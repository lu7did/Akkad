picoKeras v0.1.43 - CLI consolidation (incremental patch over v0.1.42)

Exactly four public PowerShell entrypoints:
  .\scripts\keras_download.ps1 https://host/direct-file.keras
  .\scripts\keras_tflite.ps1 .\small.keras
  .\scripts\keras_int8.ps1 .\small.tflite
  .\scripts\keras_listen.ps1 .\small.int8.tflite 6110

Commands are relative to your current shell working directory, so use paths
as appropriate. All tools use Python from the active 'ufasta' environment.

The FP32 step calls keras_fp32_export.py -> export_graph.make_export_model(
integer_square=True). The INT8 step calls the previously validated
int8_pipeline.py with --source clone --integer-square, then
staticize_reshape.py to freeze batch=1 reshapes (43 in the validated model).
The output is named small.int8.tflite. The temporary
small.int8.raw.tflite and machine-readable reports remain for provenance.

The INT8 stage still needs the original Keras file and the source.json
manifest generated by keras_tflite.ps1: a TFLite FP32 file alone does not
contain the trainable Keras graph required by the original conversion method.

The listener uses the existing Release executable and starts TCP on 0.0.0.0,
port 6110 by default; it DOES NOT start in --stdio mode. Stop with Ctrl+C.

The user confirmed v0.1.42 UCI bestmove d2d4 using the frozen INT8 model.
This patch itself has only static checks (no Windows/TensorFlow runtime here).
